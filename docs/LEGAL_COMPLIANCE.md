# TalkFrog — чек-лист комплаенса и модерации

Документ для продуктовой и юридической сверки перед релизом. Не заменяет консультацию юриста.

## 1. Общие принципы

- [ ] Персональные и **голосовые** данные обрабатываются только с **явным согласием** (отдельный пункт от общих условий).
- [ ] Политика конфиденциальности и пользовательское соглашение **на русском**, доступны до регистрации и в настройках.
- [ ] **Удаление аккаунта** и связанных данных — self-service или запрос с SLA (указать в политике).
- [ ] **Восстановление покупок** (IAP) — видимая функция в приложении.
- [ ] API-ключи (Gemini и др.) **только на сервере**; аудит репозитория перед каждым релизом.

---

## 2. Apple App Store

- [ ] Guideline 1.2 — UGC/ИИ: модерация, жалобы, блокировка при злоупотреблениях (если применимо).
- [ ] Guideline 3.1.1 — подписки и разовые покупки через IAP; без обхода оплаты в приложении.
- [ ] Guideline 5.1.1 — Privacy: декларация сбора данных (голос, email, идентификаторы).
- [ ] `NSMicrophoneUsageDescription` — понятное **русское** объяснение в `Info.plist` / Expo config.
- [ ] Sign in with Apple — если есть сторонний вход на iOS.
- [ ] App Privacy Nutrition Labels согласованы с фактическим сбором.

---

## 3. Google Play

- [ ] Data safety form: голос, идентификаторы, покупки, шифрование в транзите.
- [ ] `RECORD_AUDIO` — обоснование в описании и в приложении до запроса.
- [ ] Billing Library актуальной версии; политика подписок.
- [ ] Families / контент для обучения — возрастной рейтинг и отсутствие запрещённого контента в ИИ-ответах (фильтры на сервере).

---

## 4. Республика Корея (PIPA)

- [ ] При наличии пользователей из Кореи: согласие на сбор **биометрических/голосовых** данных, где применимо.
- [ ] Уведомление о целях обработки, срок хранения, трансграничная передача (если серверы вне Кореи).
- [ ] Права субъекта: доступ, исправление, удаление.
- [ ] Локальный контакт / DPO при масштабе, требующем регистрации.

---

## 5. Российская Федерация (152-ФЗ)

- [ ] Согласие на обработку ПДн (отдельная форма/чекбокс).
- [ ] Политика обработки ПДн с целями, правовыми основаниями, сроками.
- [ ] Хранение ПДн граждан РФ — учёт требований локализации при применимости (оценка инфраструктуры Supabase/регионов).
- [ ] Право на отзыв согласия и уничтожение данных.
- [ ] Уведомление Роскомнадзора — при статусе оператора (решение юриста).

---

## 6. Страны СНГ (базовый унифицированный набор)

- [ ] Единая политика конфиденциальности с адаптацией под локальные ссылки при расширении.
- [ ] Согласие на обработку голоса и возможная трансграничная передача на обработку ИИ.
- [ ] Возрастное ограничение и согласие законного представителя для несовершеннолетних (если целевая аудитория включает детей).

---

## 7. Голосовые данные (продуктовые требования)

- [ ] Запись только после согласия и системного разрешения.
- [ ] Минимизация: не хранить сырой аудиофайл дольше, чем нужно для урока, если политика иная — описать в политике.
- [ ] Шифрование HTTPS; доступ к storage только через RLS / signed URLs.
- [ ] Возможность пользователя запросить удаление голосовых артефактов вместе с аккаунтом.

---

## 8. Монетизация и возвраты

- [ ] Прозрачные тарифы на русском.
- [ ] Соответствие правилам Apple/Google по отмене подписок.
- [ ] Синхронизация статуса подписки в Supabase для гостевых/кросс-девайс сценариев после привязки аккаунта.

---

## 9. ИИ (Gemini)

- [ ] Промпты без инъекции пользовательского контента в системные инструкции без экранирования.
- [ ] Логирование без ПДн в открытых логах.
- [ ] Запрет выдачи ключей/внутренних URL в ответах модели (серверные guardrails).

---

## 10. Перед публикацией (release gate)

- [ ] Юридический ревью текстов согласий.
- [ ] Тест удаления аккаунта end-to-end.
- [ ] Тест restore purchases на iOS и Android.
- [ ] Проверка отсутствия секретов в бандле (`grep`, CI).
